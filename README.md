# PAWS — Program for Automating reporting on Work Shifts

> Программа для автоматизации учета рабочих смен, хранения сведений о выполненной работе и формирования отчетности.

## О проекте

**PAWS** (Program for Automating reporting on Work Shifts) — программное обеспечение для автоматизации учета рабочих смен сотрудников и подготовки отчетной документации.

Проект разрабатывается в рамках учебной работы по дисциплине **«Программная инженерия»**. Программа предназначена для централизованного хранения информации о рабочих сменах и предоставления пользователю оперативного доступа к необходимым данным.

Основная задача проекта — сократить время на оформление отчетности, уменьшить количество ошибок при ручном вводе данных и упростить подготовку итоговых отчетов.

## Основные возможности

- авторизация пользователей и разграничение прав доступа;
- добавление, просмотр, изменение и поиск данных о сотрудниках;
- регистрация рабочих смен с указанием временной метки начала и окончания работы;
- автоматическая фиксация продолжительности смены;
- внесение и хранение сведений о выполненных работах;
- редактирование и просмотр истории рабочих смен;
- поиск рабочих смен по заданным параметрам;
- формирование отчетов за выбранную дату или период;
- формирование отчетов для выбранного сотрудника или группы сотрудников;
- экспорт отчетов в **PDF** и **XLSX**;
- автоматическая подготовка итоговых показателей по рабочим сменам.

## Пользователи

В системе предусмотрены следующие категории пользователей:

| Роль | Возможности |
|---|---|
| **Сотрудник** | Ввод и корректировка информации о рабочих сменах |
| **Руководитель** | Просмотр информации и получение отчетов |
| **Администратор** | Настройка и обслуживание программного обеспечения |

## Основные данные системы

Программа работает со следующими основными информационными объектами:

- **Сотрудник** — сведения о работнике, участвующем в выполнении рабочих смен.
- **Рабочая смена** — информация о периоде работы сотрудника, включая временные метки начала и окончания смены и продолжительность.
- **Выполненная работа** — сведения о работах, выполненных сотрудником в течение рабочей смены.
- **Отчет** — сформированный системой документ со сведениями о рабочих сменах за выбранный период.

## Отчетность

PAWS поддерживает формирование отчетов на основании данных, хранящихся в системе.

Доступны следующие типы отчетности:

- **Ежедневный отчет** — сведения о рабочих сменах за выбранную календарную дату.
- **Сводный отчет за период** — сведения о рабочих сменах за заданный временной интервал с итоговыми показателями.

В отчетах могут отображаться:

- сведения о сотруднике;
- временная метка начала и окончания смены;
- продолжительность смены;
- сведения о выполненных работах;
- количество смен;
- суммарная продолжительность отработанного времени.

### Экспорт

Сформированный отчет может быть сохранен в следующих форматах:

- **PDF** — для просмотра, передачи и печати;
- **XLSX** — для дальнейшей обработки в табличных редакторах.
